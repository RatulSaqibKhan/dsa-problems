# 🧩 Problem: Count the Number of Digits in an Integer

## 📘 Problem Statement:
Given a non-negative integer n, write a function that returns the total number of digits present in n.

## Input
  - a non-negative integer `n`

## Output
  - the number of digits in the number.

## Constraints
  - `0 <= n <= 10^18`

## Example
```
Input: n = 4725
Output: 4
Explanation: The number 4725 has 4 digits: 4, 7, 2, and 5.
```
## 🚫 Restrictions:
- Do not use string conversion (str(n)) to solve this problem.
- Solve it using pure mathematical operations (modulus %, division //, or logarithmic math).
