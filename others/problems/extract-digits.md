# Extract Digits from a Given Number

## Problem Statement

Given a non-negative integer `n`, extract and return all of its digits in an array in the same order as they appear in the number.

## Input
 - a non-negative integer `n`

## Output
- an array in the same order as they appear in the number.

## Constraints
- `0 <= n <= 10^9`

## Example 1

```
Input: n = 4725
Output: [4, 7, 2, 5]
```

## Bonus
Can you solve it:

1. Without converting to a string?
2. Using recursion?
